# 接单订单雷达（Order Radar）

针对程序员外包平台的**自动订单监控工具**：抓取平台订单列表，按技能关键词自动筛选匹配项目，生成可直接投递的订单报告，并自动识别风险订单。

## 功能
- 自动抓取外包平台（猿急送）远程/全部订单列表
- 按技能关键词（AI/Agent/MCP/Python/数据/网站/小程序等）自动筛选匹配订单
- 自动识别风险订单（私服、金融灰产等）并标注提醒
- 生成 Markdown 报告：含预算、工时、命中关键词、投递链接
- 结果自动保存为时间戳报告文件

## 用法（Windows）
```powershell
powershell -ExecutionPolicy Bypass -File "订单雷达.ps1"
```

## 输出示例
```
======== 订单雷达报告 ========
抓到订单总数: 20    匹配技能: 12
✔ [24000元/30天] AI应用后端工程师（AI Agent 方向）
    命中: ai、agent、mcp、大模型
✔ [1600元/2天] 橘子选股系统（Python+AKShare）
⛔ 风险单: 乱舞三国OL（私服）、MT5马丁EA（金融灰产）
报告已保存: 订单雷达报告-YYYYMMDD-HHmm.md
```

## 自定义
编辑脚本开头的 `$keywords` 数组即可调整筛选关键词（技能标签），`$riskWords` 调整风险识别词。

## 技术栈
PowerShell · 网页抓取 · 正则解析 · 命令行工具
